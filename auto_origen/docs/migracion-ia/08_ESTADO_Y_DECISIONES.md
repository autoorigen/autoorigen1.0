# DECISIONES Y PRINCIPIOS

## Decisiones confirmadas

- La aplicación será nativa iOS.
- Se utiliza SwiftUI.
- El proyecto se llama `AutoorigenInspect`.
- Nombre visible: `AO`.
- La inspección debe ser una sesión persistente.
- Los medios deben asociarse a la inspección.
- Existirá una sección `Mis Inspecciones`.
- El usuario quiere aprender mientras desarrolla.
- Se quiere mantener el proyecto escalable.

## Decisiones de producto

La aplicación debe documentar evidencia real del taller.

No debe limitarse a tomar fotos: debe mantener relación entre:
vehículo → inspección → evidencia → hallazgo → informe.

## Filosofía de desarrollo

Pequeños cambios.
Prueba después de cada cambio.
Explicación antes del código.
No ocultar errores.
No inventar persistencia.
No saltar a funciones avanzadas antes de estabilizar el flujo base.
