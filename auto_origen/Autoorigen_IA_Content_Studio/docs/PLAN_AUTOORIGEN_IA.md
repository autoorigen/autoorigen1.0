# Plan de evolución

## Módulo 1 — Transcripción
- Whisper local
- timestamps
- SRT/VTT
- identificación de idioma

## Módulo 2 — Comprensión del contenido
Extraer:
- marca
- modelo
- año si aparece
- falla
- síntomas
- diagnóstico
- piezas
- reparación
- resultado

## Módulo 3 — Contenido
Generar:
- hook
- Reel 30 s
- Reel 60 s
- YouTube
- Facebook
- WhatsApp
- título
- descripción
- CTA
- hashtags

## Módulo 4 — Biblioteca
Cada video debe quedar asociado a:
- vehículo
- placa/identificador interno
- trabajo
- fecha
- categoría
- estado
- publicación

## Módulo 5 — Edición
Automatizar:
- cortes por silencios
- subtítulos
- formato vertical 9:16
- extracción de clips
- antes/después

## Módulo 6 — Voz
Integrar MeloTTS/OpenVoice de forma opcional.

## Módulo 7 — Ecosistema
Conectar la IA con la aplicación y página web de Autoorigen mediante una API local.
